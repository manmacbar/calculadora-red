¿Qué es una subred IPv4?

Una subred IPv4 es una división lógica de una red IP. El prefijo CIDR indica cuántos bits pertenecen a la parte de red y cuántos quedan disponibles para las direcciones de los dispositivos.

Por ejemplo, una red 192.168.1.0/24 utiliza una máscara 255.255.255.0 y contiene 256 direcciones IPv4 en total.

¿Qué calcula esta calculadora?

A partir de una dirección IPv4 y un prefijo CIDR, la herramienta calcula automáticamente:

  • Dirección de red.
  • Máscara de subred.
  • Wildcard.
  • Dirección de broadcast.
  • Primer host.
  • Último host.
  • Número de hosts utilizables.
  • Número total de direcciones.

Ejemplo de una red /24

Si introduces 192.168.1.50/24, la dirección IP pertenece a la red 192.168.1.0/24.

En este caso, la red tiene 256 direcciones en total, desde 192.168.1.0 hasta 192.168.1.255. En una red convencional /24, las direcciones de red y broadcast no se asignan a hosts, por lo que quedan 254 hosts utilizables.

¿Qué significa CIDR?

CIDR significa Classless Inter-Domain Routing. La notación utiliza una barra seguida de un número, como /24, /27 o /30, para indicar el tamaño del prefijo de red.

Cuanto mayor sea el prefijo, menor será el número de direcciones disponibles dentro de la red.
